# aurora-gradient-photo

**Family:** texture. **Wants:** fills its panel for the whole shot. **Source:** Framer's "skills" ad
(instagram.com/p/DdtwW_Ws0Xx), studied 2026-10-07.

## Looks

A soft diagonal wash of two or three colours stands in for a photograph inside an interface mock-up. It reads
as imagery without sourcing a real photo or showing a real person.

## Build

- A canvas linear or conic gradient in the brand's colours, plus seeded noise for grain.
- Or stacked CSS gradients with blend modes.
- Drift the gradient's angle and stops slowly on the clock, so the image is alive.

## Adapting

Use it wherever a mock-up needs a picture. The film never needs a real person's photo.
