# bounce-path-draw

**Family:** data, physics. **Wants:** 2-3 s. **Source:** prompt-motion.com's gallery, studied 2026-10-07.

## Looks

A thin line draws itself behind a moving or bouncing object, segment by segment, so the path stays on screen
as a record of the motion.

## Build

- One 2D canvas from the master clock.
- Sample the object's motion function at fine steps from its start time to `t`, and stroke the polyline up
  to the current sample (a progressive reveal).
- Use a thin accent stroke with a slight glow, and the object drawn on top.

## Sound

A soft tick on each bounce.

## Adapting

Use it for a journey (visitor to call, idea to launch), a trend, or the through-line dot leaving its trail
across a scene.
