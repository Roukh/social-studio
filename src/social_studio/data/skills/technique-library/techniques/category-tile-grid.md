# category-tile-grid

**Family:** data, interface. **Wants:** 1.5-2.5 s. **Source:** reyzostyle-b55864
(prompt-motion.com/reyzostyle-b55864), studied 2026-10-09.

## Looks

Dozens of small, differently coloured tiles fill in behind a bold headline, each carrying a short label (a
topic, a format, a category), arriving on a loose stagger until the grid is dense — deliberately too many to
read individually, so the shot sells breadth and a little overwhelm, a beat before the product narrows it down.

## Build

- A CSS/DOM grid of fixed-size cards, each with a random accent fill from a small palette and a short label.
- Cards scale and fade in (`0 -> 1`, `power2.out`) on a per-card seeded delay so the build feels organic, not a
  wipe or a single stagger direction.
- Keep the headline layered above the grid at full contrast so it reads first; the grid is texture, not the
  message.

## Sound

A fast, granular patter of soft ticks as the tiles land, overlapping into a wash by the time the grid is full.

## Adapting

Use for "so many options/ideas/categories" beats in any niche-finding, discovery or library product. Swap the
labels for the brief's own categories; never leave placeholder words on screen.
