# command-chip-cycle

**Family:** type, interface. **Wants:** 1.7-2.5 s. **Source:** Framer's "skills" ad
(instagram.com/p/DdtwW_Ws0Xx), studied 2026-10-07.

## Looks

A glowing rounded pill (a command, a tag, a mode) types in. It cycles through two or three names, one per beat,
and the last one holds, larger and brighter, as the shot's payoff.

## Build

- A DOM pill with a glow from a `box-shadow` and a blurred duplicate layer.
- Each name swaps with a quick scale and opacity change on the beat. The final glow ramps up from the clock.
- Type the first name with `kit.typeOn`, then cut the rest in on the beat.

## Sound

A blip per swap and a riser into the final brighten.

## Adapting

Any choice that lands on one answer: a plan, a feature, a word. The final name is the film's word.
