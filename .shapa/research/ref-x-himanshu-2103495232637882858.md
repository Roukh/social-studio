### Style guide

- **Palette** (sampled from pixels + by eye): near-white ground #D3D2D5, near-black ground #181820/#1C1D22,
  ink text #191A1F, a single saturated blue accent (dot, type fills, particles, dial), and a marker
  red/pink (~#FF8EAA) used only for hand-drawn annotation ink (arrows, strike-throughs, checkmarks) -
  never as a scene fill. Two neutral grounds alternate; nothing else fills a frame.
- **Type**: a heavy condensed display grotesk for the title and end card ("I MAKE THINGS MOVE.",
  "MOTION DESIGNER CLAUDE."), a plain bold sans for the flashed words (BOUNCE/STRETCH/SPIN/SNAP), and a
  casual handwritten/marker script for every annotation label and arrow - the same contrast a textbook or
  Kurzgesagt-style explainer uses between "the statement" and "the margin note."
  SPIN is deliberately smeared by heavy motion blur ("rotateY 450deg" is readable only as an annotation,
  not in the blurred word itself) - the blur is the content, not a flaw.
- **HUD**: a thin running timecode top-right ("00:00:03:09") and a persistent bottom timeline bar: a track
  with a moving playhead tick and diamond markers (filled = passed, hollow = upcoming), i.e. the film shows
  its own keyframes as it goes, on every scene including the end card.
- **Texture**: a faint dot grid on every ground (light or dark), soft radial vignette, motion-trail ghost
  circles standing in for onion-skin frames during the bounce.

## Principles

What generalises beyond this one film (recorded as rules below, with times as evidence):

1. Annotate the mechanism in the same frame as the motion, synced to the beat it appears, in a hand-drawn
   style visually distinct from the display type.
2. A held shot can run 2-3 s longer than the usual beat-grid turnover when it is visibly still being built
   (a curve drawing itself, a dial counting up) rather than sitting static.
3. A restrained two-neutral-plus-one-accent palette, with a second colour reserved only for annotation ink,
   is a legitimate alternative to a multi-colour rotating full-bleed palette.
4. For a capability-demo brief, make the shot's subject the literal technique being executed (a bounce
   that teaches squash and stretch) rather than an arbitrary scene that merely looks impressive.
5. A word-flash montage (one word, one hard cut, ~0.4-0.5 s each) is one scene's internal beat grid, not
   several scenes - plan and tag it as a single shot-list entry with sub-beats.

## Techniques

Candidate library entries this reference supports:

- **slug:** `annotated-diagram-overlay` · **family:** type, annotation · **looks:** a short hand-drawn label
  and arrow pop onto the exact element being demonstrated (a bounce, a curve, a stagger), in a casual
  script distinct from the display font, timed to an onset · **wants:** 0.8-2.5 s per label, reusable across
  any shot · **build:** DOM text + SVG/stroke-animated arrow path (`strokeDashoffset` draw-on), GSAP
  timeline entry keyed to the master clock; never a separate caption bar · **sound:** a tick on each label's
  arrival.
- **slug:** `easing-graph-draw` · **family:** data, annotation · **looks:** a position-vs-time graph draws a
  straight line labelled "linear = robotic" in red, then redraws as an S-curve with a checkmark; small boxes
  along a timeline bunch and spread to match the curve's spacing · **wants:** 2.5-3 s · **build:** canvas 2D
  from the master clock: draw the path with a progressive `lineTo` reveal, drive the marching boxes'
  x-position by the same eased function being taught · **sound:** quiet bed, a tick per box.
- **slug:** `squash-stretch-ball-demo` · **family:** physics, annotation · **looks:** a ball falls with
  ghost-circle motion trail (visible spacing), squashes on landing, stretches on the rebound, each beat
  hand-labelled · **wants:** 1.5-2 s · **build:** canvas 2D, draw N trailing copies of the ball at past
  frame positions with falling opacity to show spacing directly · **sound:** a thump on the squash.
- **slug:** `particle-flow-comet` · **family:** particles, generative · **looks:** a dark dotted field with a
  faint vector-flow background; a comet trail of coloured dots traces a looping path (figure-8 works well),
  labelled with the principle it demonstrates · **wants:** 2-2.5 s · **build:** canvas 2D or three.js
  points, trail as a ring buffer of past positions with per-point size/opacity falloff · **sound:** a riser
  under the loop.
- **slug:** `radial-progress-anticipation` · **family:** data, interface · **looks:** a ring progress bar
  fills while a percentage counts up; loose squares orbit it; before each step the main dot pulls back
  slightly before advancing (true anticipation, not just a tween) · **wants:** 1.5-2 s · **build:** canvas
  2D or SVG stroke-dashoffset ring, counter driven by the master clock, a small negative pre-move before
  the forward move · **sound:** ticks on each percentage tier.
- **slug:** `timeline-scrubber-hud` · **family:** frame, structure · **looks:** a persistent bottom bar
  showing a track, a moving playhead tick, and diamond keyframe markers (filled past, hollow upcoming),
  running the whole film · **wants:** the whole film · **build:** one DOM/SVG bar driven by the master
  clock's `t / duration`; markers placed at each scene's start time · **sound:** none (visual only).
